# Query/initial-population

- 合意状態：ユーザーが修正を承認。
- 実装状態：修正・検証中。ac000e2とEntity再入修正後の配布物で再現。

Entityを生成してdestroyした後、初めてworld.query()を呼ぶと破棄済みEntityが結果に入る。world.entitiesには含まれず、entity.isAlive()はfalse。生成直後にQueryを一度作っておいた経路では再現しない。

```ts
const world = createWorld();
const entity = world.spawn();
entity.destroy();
entity.isAlive(); // false
world.query();   // 実際には破棄したentityを含む。期待値は空。
```

次はQueryの初期集合生成とEntity indexの生存範囲を確認する。削除再入の修正とは独立した不具合で、neko側への影響は未評価。
