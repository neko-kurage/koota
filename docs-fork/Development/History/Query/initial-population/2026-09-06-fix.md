# 初回Queryへの破棄済みEntity混入の修正

作業ID：Query/initial-population。2026-09-06、ユーザーの修正依頼によりfeature/query-initial-populationで実施。基準494fc4c。

Entity indexのdense配列は、先頭に生存個体、末尾に再利用待ちの破棄済みslotを保持する。Queryの初期生成が配列全長を走査していたため、Traitを要求しない条件やRemovedに破棄済みEntityが混ざっていた。通常・追跡の両方でaliveCountを上限にする。個体ごとの生存lookupや配列copyを追加しない。

修正前は追加3テストが失敗し、修正後は成功。空Query（IncludeDisabledあり／なし）、Not、番号再利用、生存個体のTrait除去と破棄を区別したRemovedの初期集合を確認した。verify-forkで型、collections 23・core 153・React 37のsourceテスト、生成配布190テスト、build、packを検証した。

[通常の初回Query生成](../../../Performance/Query/initial-population/2026-09-06-measurements.md)も測定した。初期化範囲の修正を採用し、[現行契約](../../../../Architecture/Structure/Query/01-initial-population.md)へ反映してAuditから削除。既存Queryの増分通知、ゲーム状態のrollback、nekoのcleanup方針は変更しない。

nekoの同梱tgzはac000e2のまま。削除再入修正と今回の修正を含む配布物の導入はKoota/distributionとnekoのfork-integrationで追跡する。remoteへのpush・公開は行っていない。
