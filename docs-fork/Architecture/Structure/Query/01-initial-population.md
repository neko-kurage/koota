# Queryの初期集合

Worldへ初めてQueryを登録するとき、初期集合の候補はその時点で生存するEntityに限る。Entity番号の再利用待ち領域は候補に含めず、再利用済みなら現在の世代のEntityを一度だけ扱う。空Query・否定条件でもこの生存条件を省略しない。

通常Queryと追跡Queryの初期集合に同じ生存範囲を使う。Removedの初期集合では、生存しているEntityからのTrait除去を扱い、破棄済みEntityを初期候補へ戻さない。既に登録されている追跡Queryが増分で蓄積した通知結果の扱いは、初期集合生成とは別である。

IncludeDisabledは生存中のdisabledなEntityを含める指定であり、破棄済み参照を含める指定ではない。
